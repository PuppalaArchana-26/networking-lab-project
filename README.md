# Cisco Networking Lab Project

## Overview
This project demonstrates basic enterprise networking concepts using Cisco devices, including routing, switching, and troubleshooting common network issues.

## Skills Used
- Cisco Routers & Switches
- LAN/WAN Configuration
- IP Addressing & Subnetting
- DNS, DHCP, and VPN troubleshooting
- Basic network analysis using Wireshark

## What I did
- Designed a simple network topology
- Configured basic router and switch settings
- Simulated connectivity between devices
- Identified and fixed common network issues
- Captured and analyzed network traffic using Wireshark

## Tools Used
- Cisco Packet Tracer
- Wireshark
- Networking fundamentals

## Purpose
To demonstrate hands-on networking skills for entry-level Network Engineer roles.
